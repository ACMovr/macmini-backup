Privacy policy – macmini-backup

Last updated: 17 November 2026

What the app is

macmini-backup is a personal backup tool used by a single person, its owner, to back up their own home server to their own Google Drive. It is not offered to anyone else.

Google user data the app accesses

The app requests only the https://www.googleapis.com/auth/drive.file scope. With it, the app can create, read, update and delete only the files it has created itself (the backup files). It cannot see, read or change any other files in Google Drive, and it does not access any other Google account data.

How the data is used and stored

All backup data is encrypted on the owner's own computer before it is uploaded, with a key that only the owner holds. Google stores only encrypted data. The OAuth token is stored only on the owner's computer.

Sharing

No data is shared with, sold to, or transferred to any third party. There is no server, no analytics and no tracking of any kind.

Retention and deletion

Old backups are deleted automatically according to a fixed schedule (7 daily, 5 weekly and 12 monthly versions). Access can be revoked at any time at myaccount.google.com/permissions, after which the backup files can be removed from Google Drive.

Contact

Questions about this policy can be raised through the GitHub repository that hosts this page.
